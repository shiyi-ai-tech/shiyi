# 史佚(ShiYi) 飞书应用配置指南

本文档详细说明如何从零开始创建飞书机器人并配置史佚网关。

## 1. 创建飞书应用

1. 打开 [飞书开放平台](https://open.feishu.cn/app)，使用飞书账号登录
2. 点击「开发者后台」→「创建企业自建应用」
3. 填写：
   - **应用名称**：如 `史佚` 或自定义
   - **应用描述**：AI 记忆助手
   - **应用图标**：上传图标（可选）
4. 点击「创建」

## 2. 启用机器人能力

1. 左侧菜单「应用功能」→「机器人」
2. 开启「启用机器人」
3. 填写机器人名称和描述
4. 点击「保存」

## 3. 获取应用凭证

1. 左侧菜单「凭证与基础信息」
2. 复制 **App ID**（格式：`cli_xxxxxxxxxxxx`）
3. 复制 **App Secret**
4. 填入史佚的渠道配置页面（或写入 `gateway.yaml`）

⚠️ App Secret 务必保密，不要提交到代码仓库。

## 4. 配置权限（批量导入）

**推荐使用批量导入**，避免遗漏：

1. 左侧菜单「开发配置」→「权限管理」
2. 点击「批量导入/导出权限」按钮
3. 选择「应用身份权限」页签
4. 将以下 JSON 粘贴到输入框，点击「格式化 JSON」
5. 确认权限清单无误后，点击「申请开通」

```json
{
  "scopes": {
    "tenant": [
      "im:message",
      "im:message:send_as_bot",
      "im:message:readonly",
      "im:resource",
      "im:chat",
      "im:chat:readonly",
      "im:chat:member"
    ]
  }
}
```

### 权限说明

| Scope | 权限名称 | 用途 |
|---|---|---|
| `im:message` | 获取与发送单聊、群组消息 | 发送、回复消息 |
| `im:message:send_as_bot` | 以应用身份发消息 | 群聊中以机器人身份发消息 |
| `im:message:readonly` | 读取消息 | 读取消息内容 |
| `im:resource` | 获取与上传图片或文件资源 | 上传图片/文件到消息 |
| `im:chat` | 获取与更新群组信息 | 群聊功能 |
| `im:chat:readonly` | 获取群组信息 | 读取群组列表 |
| `im:chat:member` | 获取群组成员 | 群成员管理 |

> 注意：敏感权限需要管理员审批。申请理由可填：「本应用为 AI 记忆助手，需要消息收发和文件处理功能以提供完整的对话体验。」

## 5. 配置事件订阅

1. 左侧菜单「事件与回调」→「事件订阅」
2. 订阅方式选择 **「使用长连接接收事件」**（WebSocket 模式，无需公网服务器）
3. 添加事件：`im.message.receive_v1` — 接收消息
4. 点击「保存」

## 6. 发布应用

1. 左侧菜单「版本管理与发布」→「创建版本」
2. 填写版本号（如 `1.0.0`）和更新说明
3. 点击「申请线上发布」
4. 等待管理员审批

> 审批通过后，应用即可在飞书中使用。

## 7. 配置史佚

### 方式一：WebUI 配置（推荐）

1. 打开 `shiyi webui`
2. 进入「设置」→「渠道连接」
3. 展开「飞书」，填入 App ID 和 App Secret
4. 点击「保存」，然后点击「测试连接」验证
5. 测试通过后重启 `shiyi webui`，网关会自动启动

### 方式二：配置文件

创建 `~/.shiyi/gateway.yaml`：

```yaml
feishu:
  app_id: "cli_xxxxxxxxxxxx"
  app_secret: "xxxxxxxxxxxxxxxxxxxx"
```

## 8. 添加机器人到群聊

1. 群聊右上角 ⋯ →「群机器人」→「添加机器人」
2. 选择你的机器人
3. 群内 @机器人 即可触发对话

## 常见问题

**Q: 消息发送失败，提示权限不足**
- 检查权限配置页面，确认所有权限已添加且状态为「已生效」
- 权限添加后需要发布版本才生效

**Q: 收不到消息**
- 确认事件订阅方式为「长连接」
- 确认 `im.message.receive_v1` 事件已添加
- 检查网关进程是否正常运行

**Q: 群聊@机器人无响应**
- 确认机器人已添加到群
- 确认群聊相关权限已配置

**Q: 测试连接失败**
- 检查 App ID 和 App Secret 是否正确
- 确认应用已创建并启用机器人能力
